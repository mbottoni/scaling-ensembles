\begin{abstract}
This report studies whether independently trained neural networks become more
functionally similar as their parameter count increases. The starting point is
Fort, Hu, and Lakshminarayanan's ``Deep Ensembles: A Loss Landscape
Perspective'', which argues that deep ensembles work well because independent
random initializations explore distinct modes in function space, while
trajectory-local subspace methods tend to remain inside one prediction-space
mode. Here we reproduce a small subset of that experimental logic, but add
parameter count as the main scaling axis. This version drops the MNIST result
and focuses on harder settings: FashionMNIST, CIFAR-10, corrupted CIFAR-10
evaluation, and a longer CIFAR-10 patch-transformer schedule. We compare
accuracy, pairwise prediction agreement, Jensen-Shannon divergence where
available, ensemble gain, and linear interpolation barriers.
\end{abstract}

\section{Background}

Let a neural network with parameters $\theta$ define a predictive distribution
$p_\theta(y \mid x)$ and a class prediction
\[
    f_\theta(x) = \arg\max_y p_\theta(y \mid x).
\]
Deep ensembles train several networks from different random initializations,
producing parameters $\theta_1,\dots,\theta_M$. The ensemble prediction is
usually the arithmetic mean of predictive distributions:
\[
    p_{\mathrm{ens}}(y \mid x)
    = \frac{1}{M}\sum_{m=1}^M p_{\theta_m}(y \mid x).
\]
If the ensemble members make accurate but decorrelated errors, averaging can
improve both accuracy and uncertainty estimates.

The key distinction in Fort et al. is between \emph{weight-space} similarity and
\emph{function-space} similarity. Two models may be far apart in weight space
but compute similar functions, or they may be connected by a low-loss path while
still representing substantially different classifiers. The paper therefore
measures not only loss or parameter distance, but also prediction-space
quantities such as disagreement, Jensen-Shannon divergence, and t-SNE embeddings
of softmax vectors.

\section{Connection to Fort et al.}

Fort et al. perform several experiments that motivate this project:

\begin{itemize}
    \item compare checkpoints within one training trajectory against checkpoints
    from different random initializations;
    \item visualize prediction vectors with t-SNE;
    \item sample local subspaces around one optimum using dropout, diagonal
    Gaussian approximations, low-rank Gaussian approximations, and random
    subspaces;
    \item build diversity-accuracy plots comparing independent initializations
    to subspace samples;
    \item compare baseline models, subspace sampling, deep ensembles, and
    ensemble-plus-subspace methods;
    \item test behavior under dataset shift on CIFAR-10-C and ImageNet-C.
\end{itemize}

This report focuses on a narrower question: when architecture width and
parameter count increase, do independently trained minima become more similar
as functions? This is related to the paper's diversity-accuracy plane, but uses
parameter count as an explicit independent variable.

\section{Metrics}

For a pair of independently trained models $a,b$, the experiments compute:

\begin{align}
    \mathrm{agreement}(a,b)
    &= \frac{1}{N}\sum_{n=1}^N
       \mathbf{1}\{f_{\theta_a}(x_n)=f_{\theta_b}(x_n)\}, \\
    \mathrm{disagreement}(a,b)
    &= 1 - \mathrm{agreement}(a,b).
\end{align}

The Jensen-Shannon divergence is computed from the predictive distributions:
\[
    \mathrm{JS}(p_a,p_b)
    = \frac{1}{2}\mathrm{KL}(p_a \Vert m)
    + \frac{1}{2}\mathrm{KL}(p_b \Vert m),
    \quad
    m = \frac{1}{2}(p_a+p_b).
\]
We also compute a two-member ensemble accuracy for each pair and subtract the
mean individual accuracy to estimate an \emph{ensemble gain}. Finally, to probe
loss-landscape connectivity, we linearly interpolate in parameter space:
\[
    \theta(\alpha)=(1-\alpha)\theta_a+\alpha\theta_b,\quad
    \alpha\in[0,1],
\]
and report the maximum loss barrier relative to the worse endpoint loss.

\section{Experimental Setup}

All runs used PyTorch with Apple's Metal backend (\texttt{mps}) exposed to the
process. This report uses completed series experiments rather than the original
MNIST pilot. The CNN dataset-difficulty experiments use five random seeds per
width and full training sets. The corrupted-evaluation runs train on clean
CIFAR-10 and evaluate diversity on noisy or blurred test inputs. The
patch-transformer run uses a longer schedule than the initial pilot, but remains
an optimization stress test rather than a tuned vision transformer.

The drop from FashionMNIST to CIFAR-10 changes the diversity story. FashionMNIST
models are accurate and highly agreement-heavy: pairwise disagreement stays near
6--7\%, and the two-member ensemble gain is below one percentage point. CIFAR-10
is harder and keeps substantially more functional diversity: disagreement stays
near 24--25\%, and ensemble gain is around three percentage points. This is more
consistent with the deep-ensemble intuition that harder problems leave room for
independent initializations to make complementary errors.

The corrupted evaluations are the strongest evidence that clean in-distribution
agreement can hide useful diversity. Under Gaussian noise, accuracy collapses
and pairwise agreement falls toward coin-flip levels for several widths. Under
blur, accuracy remains better, but disagreement is much higher than on clean
CIFAR-10 and ensemble gain rises to roughly five percentage points. The
near-zero interpolation barriers in several corrupted rows should be interpreted
carefully: the barrier is measured on corrupted evaluation loss, not on the
original training objective.

The longer patch-transformer schedule improves the smallest model substantially
relative to the pilot, but scaling width still does not produce a clean
accuracy or similarity improvement. Larger widths become less accurate and less
agreement-heavy, with the 512-width model behaving like an undertrained model.
This suggests that architecture family and optimization quality dominate any
simple parameter-count effect in this regime.

\section{Interpretation}

Dropping MNIST makes the conclusion less optimistic for a simple ``wider means
same function'' hypothesis. Dataset difficulty and evaluation shift matter at
least as much as parameter count.

\begin{itemize}
    \item FashionMNIST is easy enough that independent CNNs converge to highly
    similar predictors, with little ensemble benefit.
    \item Clean CIFAR-10 preserves much more diversity and meaningful ensemble
    gain even as width increases.
    \item Corrupted CIFAR-10 exposes still more disagreement, especially under
    blur, showing that diversity can reappear under dataset shift.
    \item The patch transformer remains optimization-limited: width increases
    parameters, but does not automatically improve accuracy or collapse
    functional diversity.
\end{itemize}

\section{Next Experiments}

The next version should make the harder-data claims more robust:

\begin{enumerate}
    \item Fix the numerical issue that produced missing JS-divergence rows in
    some cached pairwise metrics by clamping predictive distributions before
    KL computations, then recompute pairwise CSVs.
    \item Add true CIFAR-10-C severities rather than only one Gaussian-noise and
    one blur setting.
    \item Add SVHN or Tiny ImageNet as a genuinely different harder dataset.
    \item Train all widths to matched endpoint train loss to separate width from
    optimization quality.
    \item Tune the transformer with warmup, cosine decay, augmentation, and
    longer schedules before treating it as evidence about architecture scaling.
\end{enumerate}

\section{Conclusion}

The harder non-MNIST experiments suggest that functional similarity does not
collapse universally with parameter count. FashionMNIST already leaves little
room for ensemble diversity, but CIFAR-10 and corrupted CIFAR-10 preserve
substantial disagreement and ensemble gain. The strongest current conclusion is
that overparameterization interacts with task difficulty, shift, and
optimization. Wider models can become more similar, but harder data can keep
independent minima functionally distinct enough for ensembles to matter.
